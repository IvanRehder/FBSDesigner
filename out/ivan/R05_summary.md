# R05 — Report Intelligence Data (input)

**Modalities:** Touch and Keyboard

## Function
**F-05.1** — To submit structured intelligence reports to C2. (F-05.2 quick-flag and F-05.3 delivery-confirmation considered and dropped — .2 collapsed into .1 once Behaviour simplified; .3 is output-side, out of scope.)

## Behaviour
**Be-05.1** — Press-and-hold on Map screen → option ring opens at that location → pilot selects a preset intelligence marker → commits and sends to C2. Modality-complete redundant (Touch alone / Keyboard alone / mixed). Simpler than initial full-form authoring proposal. Voice-annotated reporting rejected here (out of R05's fixed modalities) — logged as spin-off Function.

## Structure
- **S-05.1.1** — Map view (WAD), reused. Shared with R06/R07.
- **S-05.1.2** — Option ring (radial menu overlay at selected point). Shared mechanic w/ R06/R07.
- **S-05.1.3** — Preset marker buttons (intel taxonomy).
- **S-05.1.4** — Marker glyph layer (committed markers on map).
- **S-05.1.5** — Input bindings: Touch (hold+tap) / Keyboard (bezel rotary+OSS).

Touchpad proposed as new hardware — **rejected** (not in baseline; cursor control covered by bezel rotary/UCP instead).

**Spin-off logged:** voice-annotated intelligence reporting (separate Function, Voice-in/Audio-out, not designed here).
