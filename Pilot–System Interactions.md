# Pilot–System Interactions — Modal Mapping

| Context | Function | T | Modalities |
|---|---|:-:|---|
| General | Communicate Message (system→user) | S | Screen + Audio-out |
| General | Communicate Order | S | Screen + Audio-out |
| Operate Aircraft | Select Autopilot Mode | E | Touch + Keyboard |
| Operate Aircraft | Input Autopilot Parameters | E | Touch + Keyboard |
| Operate Aircraft | Stop Using Autopilot | E | Touch + Keyboard |
| Operate Aircraft | Notify Autopilot Reached | S | Screen + Audio-out |
| Conduct Intelligence and Reconnaissance | Report Intelligence Data | E | Touch + Keyboard |
| Conduct Surveillance | Report Surveillance Event | E | Touch + Keyboard |
| Perform UAV Tactical Takeover | Initiate Takeover Request | E | Touch + Keyboard |
| Perform UAV Tactical Takeover | Command Takeover | E | Touch + Keyboard |
| Control UAVs | Input New UAV Parameters | E | Touch + Keyboard |
| Control UAVs | Expose UAV Status | E | Screen + Touch |
| Control UAVs | Communicate UAV Status | S | Screen + Audio-out |
| Employ UAV for ISR Operations | Expose ISR Sensor Data | E | Touch + Keyboard |
| Employ UAV for ISR Operations | Input Sensor Move | E | Wearable/HMD + Touch |
| Employ UAV for ISR Operations | Input Search Pattern | E | Touch + Keyboard |
| Employ UAV for Target Tracking | Command Track Target of Interest (TOI) | E | Touch + Keyboard |
| Employ UAV for Target Tracking | Set Tracking Distance from TOI | E | Touch + Keyboard |
| Conduct UAV Control Handover | Initiate Handover Request | E | Touch + Keyboard |
| Conduct UAV Control Handover | Command Handover | E | Touch + Keyboard |

*T: E = input (pilot → HMI) · S = output (HMI → pilot)*
