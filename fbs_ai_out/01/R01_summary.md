# R01 — Input Autopilot Parameters (input)

**Modalities:** Touch and Keyboard

## Function
F-01.1 + F-01.2 — Enable definition of autopilot target values (altitude, heading, speed) so the autopilot can be configured for engagement, AND ensure entered values are valid by warning/preventing impossible or unsafe entries. Note: F-01.2 (validation) is flagged as a shared function reusable across other parameter-entry requirements.

## Behaviour
Be-01.2 — Keyboard/button pathway as the primary means: the pilot enters the autopilot target values using physical buttons and a small keypad, with the system warning when an entry is invalid. Touch remains available as a fallback per project rule.

## Structure
S-01.3 — Rotary knobs/buttons around the main display (WAD bezel) to nudge values step-by-step, plus a numeric keypad panel (UCP) for direct entry of large value jumps, plus the main display (WAD) showing the values and turning red on invalid input.
