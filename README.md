# FBSDesigner — pacote para participantes

Pacote da pesquisa de doutorado sobre design de HMI assistido por IA (condição **IA**).

## Como baixar (sem precisar de conta nem de Git)

1. Clique em **`FBSDesigner_IA.zip`** na lista de arquivos acima.
2. Na página que abrir, clique no botão de download (ícone de seta para baixo, canto direito), ou use o link direto:
   https://github.com/IvanRehder/FBSDesigner/raw/pacote-participantes/FBSDesigner_IA.zip
3. Baixe também o **`manual_usuario.pdf`** (mesmo procedimento) e leia antes de começar.

## Próximos passos

Extraia o zip numa pasta e siga o manual (seção 4, Instalação). Em resumo: tenha o Python instalado e execute `iniciar_ia.bat` (Windows) ou `bash iniciar_ia.sh` (Mac/Linux). A chave de API é enviada pelo pesquisador em mensagem separada.

## Se você usa Git

```
git clone -b pacote-participantes https://github.com/IvanRehder/FBSDesigner.git
```
