# FBSDesigner — pacote para participantes

Pacote da pesquisa de doutorado sobre design de HMI (condição **sem IA / Human**).

## Como baixar (sem precisar de conta nem de Git)

1. Clique em **`FBSDesigner_Human.zip`** na lista de arquivos acima.
2. Na página que abrir, clique no botão de download (ícone de seta para baixo, canto direito), ou use o link direto:
   https://github.com/IvanRehder/FBSDesigner/raw/pacote-participantes-sem-ia/FBSDesigner_Human.zip
3. Baixe também o **`manual_usuario_sem_ia.pdf`** (mesmo procedimento) e leia antes de começar.

## Próximos passos

Extraia o zip numa pasta e siga o manual (seção 4, Instalação). Em resumo: tenha o Python instalado e execute `iniciar_human.bat` (Windows) ou `bash iniciar_human.sh` (Mac/Linux). Esta condição não usa IA e não precisa de chave de API.

## Se você usa Git

```
git clone -b pacote-participantes-sem-ia https://github.com/IvanRehder/FBSDesigner.git
```
