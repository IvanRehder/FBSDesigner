# R01 — Input Autopilot Parameters (input)

**Modalities:** Touch and Keyboard

## Function
F-01.1 — To make autopilot flight targets settable by the pilot. Goal: the pilot can commit specific numeric values (altitude/heading/speed) that become the autopilot's setpoints.

## Behaviour
Be-01.1 (primary) — Direct value entry via WAD field. Be-01.2 (complementary) — Increment/step adjustment. Be-01.3 (complementary) — Select-from-preset.

## Structure
S-01.1 Autopilot Setpoint Panel (WAD overlay) · S-01.2 numeric keypad (Touch) · S-01.3 step controls (Touch) · S-01.4 preset list (Touch) · S-01.5 bezel rotary+OSS (Keyboard) · S-01.6 UCP alphanumeric (Keyboard)
